# java-lotto-precourse
# 기능 요구사항
## - 입력
- [x] 구입 금액 입력
- [x] 당첨 번호 입력
- [x] 보너스 번호 입력
## - 출력
- [x] 구매 개수 출력 
- [x] 로또 번호 출력
- [ ] 통계(당첨내역) 출력
- [ ] 수익률 출력
## - 검증 및 parser
- [x] 문자열을 입력한 경우
- [x] 입력 받은 로또 번호를 Int형으로 변환
- [x] 1,000원 단위로 떨어지지 않는 경우
- [x] 발행할 로또 개수 계산
- [x] 당첨 번호 쉼표로 구분
- [X] 중복된 번호가 있는지 검증
- [x] 중복되지 않은 보너스 번호 검증
- [x] 6개가 아닌 로또 번호 개수 등록
- [x] 입력한 당첨번호가 1~45 사이인지 검증
## - 비즈니스 로직
- [x] 1~45 사이의 중복되지 않은 숫자 6개 발행
- [ ] 당첨 기준 금액은 아래와 같음
  - 1등 : 6개 2,000,000,000원
  - 2등 : 5개 + 보너스 번호 30,000,000
  - 3등 : 5개 1,500,000
  - 4등 : 4개 50,000
  - 5등 : 3개 5,000
- [x] 금액을 입력하면 해당 금액만큼 로또 발행 (번호는 자동)
- [ ] 잘못된 값 발생시 ERROR메시지 출력후 그 부분부터 다시 입력
- [ ] 수익률 계산
## - 테스트 목록
- [X] 로또 번호를 쉼표로 분리
- [ ] 6개의 숫자가 아닌 경우 에러 발생
- [ ] 6개의 숫자 중 중복된 수가 있다면 에러 발생
- [ ] 로또 번호가 숫자 형식이 아닌 경우 에러 발생 (공백 포함)
- [ ] 1~45 사이의 숫자가 아닌경우 에러 발생
- [ ] 보너스 번호가 기존 6개의 당첨번호와 중복된다면 에러 발생
- [ ] 구매 금액이 1000원 단위로 떨어지지 않으면 에러 발생
- [ ] 구매 가능한 로또 개수 계산
- [ ] 로또 번호 생성 테스트
- [ ] 당첨 수익률 계산
# 프로그래밍 요구사항
- [ ] 함수 길이는 15라인을 넘어가지 않도록
  - [ ] 함수가 단일 책임 원칙을 고수하도록
- [ ] else 사용 금지
- [ ] Enum을 적용하여 구현
- [ ] 단위 테스트 작성 단 UI는 제외
